# 深海图鉴 · Ocean Atlas

博物馆式的海洋生物 3D 图鉴。打开先走进策展路径（`src/journey.js`）：浅海礁盘 → 大洋上层 → 暮光与深渊 → 极地冰缘。每一翼有一段策展说明、本翼的物种，以及「继续 / 下一展区」。科目索引和「全部」仍在左侧，给想自己翻柜的人。

八件旗舰按生态瞬间陈列，进入时锁定与墙上那一句一致的姿态，并加重该栖息地的光和雾：眼斑双锯鱼（钻进海葵）、大白鲨（从光下跃身）、绿海龟（海草床啃食）、宽吻海豚（跃出浪尖）、抹香鲸（垂直睡眠）、大王乌贼（暮光对视）、鮟鱇鱼（一盏冷灯）、吸血鬼乌贼（收集海洋雪）。其余物种保持图鉴水准。极地主柜的虎鲸另有一块轻铭牌：打开就停在已有的「沿冰跃出」剪辑上，金句也只说这一头。它不进旗舰名单，也不另做旁白。分享卡片用每种的金句，深链仍是 `?id=`。

用 Vite + Three.js 在浏览器里浏览三十三种物种，旋转、缩放并阅读。网格模型在 `public/models/*.glb`。窄屏用左侧抽屉和底部详情面板。

静态 GLB 在运行时叠加程序化活体运动（`src/aliveMotion.js`）：按物种做顶点起伏，并带有起伏、偏航和姿态循环。每种生物会按程序循环切换具名行为（狩猎、求偶、觅食、诱捕、隐匿、展示、跃出等），并加大俯仰、横滚以及振幅与频率调制。画布下方的行为标签可锁定当前物种的具名姿态，或回到自动循环。

每种物种有自己的取景（`src/framing.js`：距离、视野、目标点）。甘氏巨螯蟹、多棘海盘车、雀尾螳螂虾、大王具足虫、紫海胆沿用原来的共享机位。

右下角「潜水员」打开比例对比：旁边站一名身高 **1.75 米** 的低面潜水员，物种按 `src/sizes.js` 里的成体典型尺寸缩放（全长、壳径、伞径、翼展、腿展等）。尺寸依据 FishBase 常见体长、NOAA Fisheries、IUCN 与 Smithsonian Ocean / FAO 的成体描述，不是纪录极值。狮鬃水母按伞径（模型里的触手是缩短的），僧帽水母按浮囊长。

窄屏只下载当前物种的 GLB，切换后卸掉上一个；桌面仍会预取下一种。环境与环境音按栖息地分开：深海、暮光带、浅海珊瑚礁、开阔大洋、海面、近岸底栖、深海底栖、近岸浅海。极地冰缘用自己的冰缘环境音（`amb-ice`），不再借开阔大洋。

八件旗舰在打开那一个瞬间时各播一句旁白（`public/audio/vo-<id>.mp3`），可点「跳过旁白」，跟右下角的总静音走，不循环，也不对另外二十五种念。抹香鲸和大王乌贼对看时响一声，棱皮龟和狮鬃水母对看时另响一声。走进极地借展（座头鲸、棱皮龟）时有一声短的「借展」耳标。四翼都盖过戳再回来，声音开着时，每次打开页面轻声一句「欢迎回来」；同一会话里护照再打开也不会重复。

换季只改 `src/journey.js` 里的 `SEASON`：名称、3–5 个停靠、`amb`（环境音 key）、`loanSting`（借展耳标文件名）、`trailer`（可选预告路径，默认 `media/season-trailer.mp4`）、`poster`（门厅静帧）。文件还不在 `public/media/` 时，门厅条和换季条按钮都不出现，也不挡开馆。门厅预告默认收成一行（标题和一枚小播放）；点「展开预告」才看见静帧，点播放才在对话框里播，不自动播放，也不循环。收起或展开记在这台浏览器里。馆内静音时预告跟着静音。护照，以及本季停靠的分享卡，盖一枚安静的「本季特展」章，不是徽章。户籍和对看表不用为换季重写。下一季只写在 `docs/next-season-draft.md`，不改线上 `SEASON`。

海马、真蛸、大王乌贼、多棘海盘车已换上加大振幅的骨骼剪辑，行为 id 与剪辑名一致（海马 grip / brood / sip / dance，真蛸 camouflage / ink / squeeze / probe，大王乌贼 lunge / jet / duel，海盘车 crawl / evert / regenerate）。抹香鲸「喀哒定位」仍几乎不动，页面额外带动下颌。本仓库没有 blend 文件。

线上站点：https://hantrleko.github.io/ocean-atlas/

```bash
npm ci
npm run dev      # 本地预览
npm run build    # 输出 dist/
```

`vite.config.js` 已设置 `base: './'`，构建结果可直接作为 GitHub Pages 项目站点的根目录。预构建站点在 `gh-pages` 分支根目录（`index.html`、`assets/`、`models/*.glb`、`.nojekyll`）。

仓库管理员打开 [Settings → Pages](https://github.com/hantrleko/ocean-atlas/settings/pages)，Source 选 **Deploy from a branch**，分支 **gh-pages**，目录 **/ (root)**，保存。保存后 https://hantrleko.github.io/ocean-atlas/ 才会开始发布。
